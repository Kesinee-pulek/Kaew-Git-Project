# Spec 001 — สมัครสมาชิกและเข้าสู่ระบบ (R1)

| รายการ | ค่า |
|---|---|
| สถานะ | Draft — รอคำตอบในข้อ 7 Open Questions |
| อ้างอิง | Requirement R1, US-01, US-02, BR-01 – BR-07, ข้อกำหนด PDPA ในหมวดที่ไม่ใช่ฟังก์ชัน |
| ข้อจำกัด | ไม่มีการชำระเงิน บัญชีที่สมัครเองเป็นผู้เรียนเสมอ |

## 1. Goal

ผู้เยี่ยมชมสมัครสมาชิกได้เองภายใน 2 นาที โดยระบุว่าเป็นพนักงาน กฟภ. หรือบุคคลภายนอก ข้อมูลที่ได้ต้องถูกต้องพอให้ใช้กติกา "เฉพาะพนักงาน" ในการลงทะเบียนหลักสูตร (R4) ได้ทันที และสมาชิกเข้าสู่ระบบแล้วกลับไปทำต่อที่หน้าเดิมได้ โดยไม่เปิดช่องให้คนอื่นเดารหัสผ่านหรือพาผู้ใช้ออกไปเว็บภายนอก

## 2. Scope

**อยู่ในขอบเขต:** หน้าสมัครสมาชิก `/register`, หน้าเข้าสู่ระบบ `/login`, การล็อกบัญชีเมื่อเข้าสู่ระบบผิดซ้ำ, การกลับไปหน้าเดิมตาม `?next=`, การออกจากระบบ, สถานะผู้ใช้ในเมนูหลัก, การขอความยินยอมตาม PDPA ตอนสมัคร

**อยู่นอกขอบเขต:** ลืมรหัสผ่าน / ตั้งรหัสใหม่, แก้ไขโปรไฟล์และเปลี่ยนประเภทผู้ใช้หลังสมัคร, ยืนยันอีเมล (รอคำตอบข้อ 7), เข้าสู่ระบบด้วยบัญชีอื่น เช่น บัญชีองค์กร, การสร้างบัญชีผู้ดูแลระบบ, การตรวจรหัสพนักงานกับระบบฝ่ายทรัพยากรบุคคล

### 3.2 หน้าเข้าสู่ระบบ `/login`

ช่องอีเมลและรหัสผ่าน ปุ่ม "เข้าสู่ระบบ" และลิงก์ "ยังไม่มีบัญชี? สมัครสมาชิก" ที่ส่งค่า `?next=` เดิมต่อไปด้วย

### 3.3 เมนูหลัก

| สถานะ | แสดง |
|---|---|
| ยังไม่เข้าสู่ระบบ | ลิงก์ "เข้าสู่ระบบ" และ "สมัครสมาชิก" |
| เข้าสู่ระบบแล้ว | ชื่อผู้ใช้ และปุ่ม "ออกจากระบบ" |

### 3.4 ข้อความแจ้งผู้ใช้

ข้อความผิดพลาดแสดงใต้ช่องที่ผิด ถ้าผิดหลายช่องให้แสดงครบทุกช่องในครั้งเดียว

| อีเมลผิดรูปแบบ | รูปแบบอีเมลไม่ถูกต้อง |

| รหัสผ่านสั้นเกิน | รหัสผ่านต้องมีอย่างน้อย 8 ตัวอักษร |
| รหัสผ่านยาวเกิน | รหัสผ่านยาวได้ไม่เกิน 128 ตัวอักษร |
| ยืนยันรหัสผ่านไม่ตรง | รหัสผ่านไม่ตรงกัน |

| พนักงานใช้อีเมลนอก กฟภ. | พนักงานต้องใช้อีเมล @pea.co.th |
| ไม่ยอมรับนโยบาย | กรุณายอมรับนโยบายคุ้มครองข้อมูลส่วนบุคคล |

## 4. Business Rules

| รหัส | กติกา | อ้างอิง |
|---|---|---|
| AU-01 | ชื่อ-นามสกุลยาว 2–100 ตัวอักษร นับหลังตัดช่องว่างหน้า-หลัง และบันทึกค่าที่ตัดแล้ว | BR-01 |
| AU-02 | อีเมลต้องถูกรูปแบบและไม่ซ้ำกับบัญชีใดในระบบ ตัดช่องว่างหน้า-หลังและเทียบแบบไม่สนตัวพิมพ์ ระบบบันทึกอีเมลเป็นตัวพิมพ์เล็ก | BR-02 |
| AU-03 | รหัสผ่านยาว 8–128 ตัวอักษร ช่องยืนยันต้องตรงกันทุกตัว ระบบไม่ตัดช่องว่างในรหัสผ่าน | BR-03 |
| AU-04 | ต้องเลือกประเภทผู้สมัคร 1 อย่าง: พนักงาน กฟภ. หรือบุคคลภายนอก | BR-04 |

| AU-06 | พนักงาน กฟภ. ต้องใช้อีเมลโดเมน `@pea.co.th` พอดี ไม่สนตัวพิมพ์ ส่วนโดเมนย่อย เช่น `@mail.pea.co.th` ไม่ผ่าน | BR-05 |
| AU-07 | บุคคลภายนอกไม่ต้องกรอกรหัสพนักงานและสังกัด และระบบไม่บันทึกสองค่านี้ แม้มีค่าส่งมากับคำขอสมัคร | BR-04 |

## 5. Acceptance Scenarios

**AS-01 สมัครสำเร็จ (บุคคลภายนอก)** (AU-01 – AU-04, AU-08, AU-11)
- Given เป็นผู้เยี่ยมชม และยังไม่มีบัญชีอีเมล `somsri@example.com`
- When สมัครเป็น "บุคคลภายนอก" ด้วยชื่อ `สมศรี ใจดี` อีเมล `somsri@example.com` รหัสผ่าน `password1` ยืนยันตรงกัน และยอมรับนโยบาย
- Then ได้บัญชีผู้เรียนประเภทบุคคลภายนอก 1 บัญชี เข้าสู่ระบบแล้ว ไปหน้า `/` และเมนูหลักแสดง "สมศรี ใจดี"

**AS-02 สมัครสำเร็จ (พนักงาน กฟภ.)** (AU-05, AU-06)
- When สมัครเป็น "พนักงาน กฟภ." ด้วยอีเมล `somchai@pea.co.th` รหัสพนักงาน `012345` และเลือกสังกัด
- Then ได้บัญชีผู้เรียนประเภทพนักงาน ที่มีรหัสพนักงาน `012345` และสังกัดที่เลือก

**AS-03 ความยาวชื่อ** (AU-01)

| ชื่อที่กรอก | ผล |
|---|---|
| `ก` | ชื่อ-นามสกุลต้องมี 2–100 ตัวอักษร |
| `   ` (ช่องว่างล้วน) | ชื่อ-นามสกุลต้องมี 2–100 ตัวอักษร |
| `  กข  ` | ผ่าน บันทึกเป็น `กข` |
| ตัวอักษร 100 ตัว | ผ่าน |
| ตัวอักษร 101 ตัว | ชื่อ-นามสกุลต้องมี 2–100 ตัวอักษร |

**AS-04 อีเมลซ้ำ** (AU-02)
- Given มีบัญชีอีเมล `somchai@example.com` อยู่แล้ว

| อีเมลที่กรอก | ผล |
|---|---|
| `somchai@example.com` | อีเมลนี้ถูกใช้แล้ว |
| `Somchai@Example.COM` | อีเมลนี้ถูกใช้แล้ว |
| `  somchai@example.com  ` | อีเมลนี้ถูกใช้แล้ว |
| `somchai@` | รูปแบบอีเมลไม่ถูกต้อง |
| `somchai2@example.com` | ผ่าน |

**AS-05 รหัสผ่าน** (AU-03)

| รหัสผ่าน | ยืนยันรหัสผ่าน | ผล |
|---|---|---|
| `pass123` (7 ตัว) | `pass123` | รหัสผ่านต้องมีอย่างน้อย 8 ตัวอักษร |
| `pass1234` (8 ตัว) | `pass1234` | ผ่าน |
| ตัวอักษร 129 ตัว | ตรงกัน | รหัสผ่านยาวได้ไม่เกิน 128 ตัวอักษร |
| `pass1234` | `pass12345` | รหัสผ่านไม่ตรงกัน |
| `pass1234 ` (มีช่องว่างท้าย) | `pass1234` | รหัสผ่านไม่ตรงกัน |

**AS-06 ข้อมูลพนักงาน** (AU-05, AU-06)
- Given เลือก "พนักงาน กฟภ." และมีพนักงานรหัส `100001` อยู่แล้ว

| ค่าที่กรอก | ผล |
|---|---|
| รหัสพนักงาน `12345` | รหัสพนักงานต้องเป็นตัวเลข 6 หลัก |
| รหัสพนักงาน `1234567` | รหัสพนักงานต้องเป็นตัวเลข 6 หลัก |
| รหัสพนักงาน `12345A` | รหัสพนักงานต้องเป็นตัวเลข 6 หลัก |
| รหัสพนักงาน `100001` | รหัสพนักงานนี้ถูกใช้แล้ว |
| ไม่เลือกสังกัด | กรุณาเลือกสังกัด |
| อีเมล `somchai@gmail.com` | พนักงานต้องใช้อีเมล @pea.co.th |
| อีเมล `somchai@mail.pea.co.th` | พนักงานต้องใช้อีเมล @pea.co.th |
| อีเมล `Somchai@PEA.CO.TH` | ผ่าน บันทึกเป็น `somchai@pea.co.th` |

**AS-07 บุคคลภายนอกไม่มีข้อมูลพนักงาน** (AU-07)
- When เลือก "บุคคลภายนอก"
- Then ไม่เห็นช่องรหัสพนักงานและสังกัด
- And ถ้าคำขอสมัครมีรหัสพนักงานหรือสังกัดแนบมา บัญชีที่ได้ไม่มีสองค่านี้
- And เปลี่ยนจาก "พนักงาน กฟภ." เป็น "บุคคลภายนอก" หลังกรอกรหัสพนักงานไปแล้ว บัญชีที่ได้ก็ไม่มีรหัสพนักงาน

**AS-08 ต้องยอมรับนโยบาย** (AU-08)
- When กรอกครบทุกช่องแต่ไม่ติ๊กยอมรับนโยบาย
- Then สมัครไม่ได้ และเห็น "กรุณายอมรับนโยบายคุ้มครองข้อมูลส่วนบุคคล"

**AS-09 ข้อมูลไม่หายเมื่อกรอกผิด** (AU-16)
- When สมัครด้วยอีเมลที่ถูกใช้แล้ว
- Then ช่องประเภท ชื่อ อีเมล รหัสพนักงาน สังกัด และการยอมรับนโยบาย ยังมีค่าเดิม
- And ช่องรหัสผ่านและยืนยันรหัสผ่านว่าง

**AS-10 สมัครพร้อมกัน** (AU-10)
- When ผู้ใช้สองคนสมัครด้วยอีเมล `new@example.com` ในเวลาเดียวกัน
- Then มีบัญชี `new@example.com` เพียง 1 บัญชี และอีกคนเห็น "อีเมลนี้ถูกใช้แล้ว"
- And กรณีรหัสพนักงานเดียวกันให้ผลแบบเดียวกัน ด้วยข้อความ "รหัสพนักงานนี้ถูกใช้แล้ว"

**AS-11 ตั้งตัวเองเป็นผู้ดูแลไม่ได้** (AU-09)
- When คำขอสมัครแนบค่าสิทธิ์ผู้ดูแลระบบมาด้วย
- Then บัญชีที่ได้เป็นผู้เรียน และเปิดหน้าผู้ดูแลระบบไม่ได้

**AS-12 เข้าสู่ระบบไม่สำเร็จ** (AU-12)

| กรณี | ข้อความ |
|---|---|
| อีเมลไม่มีในระบบ | อีเมลหรือรหัสผ่านไม่ถูกต้อง |
| อีเมลถูก รหัสผ่านผิด | อีเมลหรือรหัสผ่านไม่ถูกต้อง |
| อีเมลถูกแต่ต่างตัวพิมพ์หรือมีช่องว่างหน้า-หลัง รหัสผ่านถูก | เข้าสู่ระบบสำเร็จ |

**AS-13 ล็อกบัญชี** (AU-13, AU-14)
- Given บัญชี `somchai@example.com` ไม่เคยเข้าสู่ระบบผิด

| เวลา | การกระทำ | ผล |
|---|---|---|
| 10:00:00 – 10:04:00 | ใส่รหัสผิดครั้งที่ 1 – 4 | อีเมลหรือรหัสผ่านไม่ถูกต้อง |
| 10:04:30 | ใส่รหัสผิดครั้งที่ 5 | บัญชีถูกล็อกถึง 10:19:30 |
| 10:10:30 | ใส่รหัสถูก | บัญชีถูกล็อกชั่วคราว ลองใหม่ได้ในอีก 9 นาที |
| 10:15:00 | ใส่รหัสผิด | ยังล็อกถึง 10:19:30 (ไม่ต่อเวลา) ลองใหม่ได้ในอีก 5 นาที |
| 10:19:30 | ใส่รหัสถูก | เข้าสู่ระบบสำเร็จ ตัวนับเป็น 0 |

- จำนวนนาทีที่เหลือปัดขึ้น เช่น เหลือ 4 นาที 30 วินาที แสดง 5 นาที
- Given ใส่รหัสผิด 4 ครั้งแล้วใส่ถูก When ใส่ผิดอีก 4 ครั้ง Then ยังไม่ถูกล็อก

**AS-14 กลับไปหน้าเดิม** (AU-15)

| ค่า `next` | หลังเข้าสู่ระบบไปที่ |
|---|---|
| `/courses/SAF-101` | `/courses/SAF-101` |
| `/courses?q=saf&page=2` | `/courses?q=saf&page=2` |
| ไม่มีค่า หรือค่าว่าง | `/` |
| `https://evil.example` | `/` |
| `//evil.example` | `/` |
| `/\evil.example` | `/` |
| `javascript:alert(1)` | `/` |
| `courses/SAF-101` (ไม่มี `/` นำหน้า) | `/` |
| `/login` หรือ `/register` | `/` |

- And กติกาเดียวกันใช้กับการสมัครสำเร็จ และกับลิงก์ไปมาระหว่างหน้าเข้าสู่ระบบกับหน้าสมัครที่ส่งค่า `next` ต่อไป

**AS-15 เข้าสู่ระบบอยู่แล้ว** (AU-17)
- Given เข้าสู่ระบบอยู่แล้ว
- When เปิด `/login?next=/courses/SAF-101`
- Then ไปหน้า `/courses/SAF-101` โดยไม่เห็นฟอร์ม

**AS-16 ออกจากระบบ** (AU-18)
- Given เข้าสู่ระบบอยู่
- When กด "ออกจากระบบ"
- Then ไปหน้า `/` เมนูหลักแสดง "เข้าสู่ระบบ" และ "สมัครสมาชิก"
- And เปิดหน้า "หลักสูตรของฉัน" แล้วถูกส่งไปหน้าเข้าสู่ระบบ

**AS-17 รหัสผ่านไม่รั่ว** (AU-19)
- Then รหัสผ่านไม่ปรากฏในหน้าเว็บ ที่อยู่หน้าเว็บ (URL) ข้อความแจ้งผล หรืออีเมลใด ๆ ทั้งตอนสมัครสำเร็จและไม่สำเร็จ

**AS-18 การเข้าถึงและมือถือ**
- Then ทุกช่องมีป้ายชื่อที่โปรแกรมอ่านหน้าจออ่านได้ และข้อความผิดพลาดผูกกับช่องที่ผิด
- And ตรวจด้วย axe แล้วไม่มี violation ระดับ `serious` หรือ `critical` ทั้งสองหน้า
- And หน้าจอกว้าง 375 px ไม่มี scroll แนวนอน

## 6. Decisions

| ประเด็น | การตัดสินใจ | เหตุผล |
|---|---|---|
| ที่อยู่หน้า | `/register` และ `/login` | requirement ใช้ `/login?next=` อยู่แล้ว ส่วนหน้าสมัครตั้งชื่อให้เข้าคู่กัน |
| สมัครแล้วเข้าสู่ระบบเลยหรือรอยืนยันอีเมล | เข้าสู่ระบบทันที | ลดขั้นตอน และผู้ดูแลคัดกรองผู้เรียนอีกชั้นตอนอนุมัติการลงทะเบียน (R5) เปลี่ยนได้ถ้าข้อ 7 ตอบว่าต้องยืนยันอีเมล |
| นับความยาวชื่ออย่างไร | นับทุกตัวอักษรรวมสระและวรรณยุกต์ เช่น `ณี` นับเป็น 2 | ตรงกับวิธีนับในหน้าเกี่ยวกับเรา (spec 002) และตรวจซ้ำได้ง่าย |
| ตัดช่องว่างในรหัสผ่านหรือไม่ | ไม่ตัด | ช่องว่างเป็นส่วนหนึ่งของรหัสผ่านได้ การตัดเองทำให้รหัสที่ผู้ใช้ตั้งไม่ตรงกับที่พิมพ์ |
| ความยาวรหัสผ่านสูงสุด | 128 ตัวอักษร | requirement ไม่กำหนด ตั้งเพดานไว้กันการส่งข้อความยาวผิดปกติ และยาวพอสำหรับวลีรหัสผ่าน |
| ข้อความตอนบัญชีถูกล็อก | บอกว่าล็อกและเหลือกี่นาที | ผู้ใช้รู้ว่าต้องรอเท่าไร แม้ข้อความนี้จะบอกว่ามีอีเมลนี้ในระบบ แต่หน้าสมัครก็บอกอยู่แล้วด้วย "อีเมลนี้ถูกใช้แล้ว" (BR-02) จึงไม่ได้เปิดเผยเพิ่ม |
| ความพยายามระหว่างล็อก | ไม่นับเพิ่มและไม่ต่อเวลา | ผู้ใช้คาดเวลาปลดล็อกได้แน่นอน และคนอื่นทำให้บัญชีถูกล็อกนานขึ้นเรื่อย ๆ ไม่ได้ |
| เวลาปลดล็อก | ครบ 15 นาทีพอดีนับจากครั้งที่ 5 ก็เข้าได้ | ขอบเขตชัด ทดสอบได้ตรงตัว |
| อีเมลพนักงาน | ต้องเป็น `@pea.co.th` พอดี ไม่รับโดเมนย่อย | ตรงตามตัวอักษรของ BR-05 ถ้า กฟภ. มีโดเมนย่อยที่ใช้จริงค่อยเพิ่มเป็นรายการ |
| บุคคลภายนอกใช้อีเมล `@pea.co.th` | ได้ | ไม่มีกติกาห้าม ผู้ที่เลือกผิดประเภทเสียสิทธิ์หลักสูตรเฉพาะพนักงานเอง |
